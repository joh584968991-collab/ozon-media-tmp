## 今日学到

### WebChat 渲染限制（用户级，重要）

- **SVG 文件通过 MEDIA: 附加显示为 "?" 占位符** — webchat 不渲染 SVG
- 用户使用 webchat 时，**SVG 视觉方案不可达**
- 兜底方案优先级：PNG/JPG > HTML（含 inline SVG）> 文本描述 > ASCII 版面
- 之前 8/18 给老板出 3 套门头招牌（SVG），全部失败 → 用户极度不满。教训：**SVG 设计稿不要走 webchat，要预先确认接收方式**

### Ozon API 关键细节（项目级）

1. **`/v1/product/pictures/import` 字段名是 `images` 不是 `pictures`** — 错字段名返 400 VALIDATION ERROR（无 detail 字段，无法从报错看出问题）
2. **图片 URL 必须用 `ir-20.ozone.ru` 内部存储 URL**，不能用 `cdn1.ozone.ru` 公网 CDN URL — Ozon 服务器间调用走内部 host
3. **新建商品（ozon_sku=0、sources=[]）拒绝接受图片更新** — 必须先清 errors、分配 sku
4. `v3/product/info/list` 不返回复杂属性（id 21841/21845）— 只返回商品基础信息 + 普通 attributes

### ozon-mcp 工具使用

- **进程内 OZON_API_KEY 可能缓存旧值** — 子进程需 `source ~/.openclaw/service-env/ai.openclaw.gateway.env` 或重启
- **正确调用方式**：直接读 env 后 import `ozon_mcp.transport.seller.SellerClient` 用 `.request('POST', path, json_body={...})`
- ozon-mcp 内部对 400 VALIDATION 也只透传 body，没有任何 hint — 自己必须看 Ozon 官方 swagger

### 跨会话通信（项目级）

- `openclaw agent run <session>` 经常**挂起无返回**（看到 start 进程，但 agent.run() 阻塞）— 不要把鸡蛋放一个篮子
- **兜底：写进度文件到 `workspace-ozon-lister/workbench/video_progress.txt` 等共享位置**，目标 agent 轮询可读
- 已经做过的兜底文件：`/Users/capper/.openclaw/workspace-ozon-lister/workbench/video_progress.txt`

### 图像处理工具选择

- **ffmpeg delogo 在 image2 muxer 上失败**（"Could not open encoder before EOF"）— 不要硬扛，换 PIL
- **PIL delogo 经验**：
  - 顶部纯色横幅（y=0）→ 直接 `ImageDraw.rectangle` fill 白色，简单稳
  - 中间带纹理的 logo → 取周边 RGB 均值采样，用 `numpy` 切片填充，自然融合
  - 加 `Image.Resampling.LANCZOS` 重采样保留边缘质量
