- 问题标题：生成器绕过合规与 CDN 验证，校验器漏检 Main profile
- 影响范围：新生成视频、jsDelivr 链接报告、Ozon 媒体属性填写前置判断。
- 当前状态：已修复并完成本地端到端验证。
- 复现条件：旧实现调用 make_carousel_video.py 后会直接进入 push_to_github，未调用 check_video_compliance.py，也不验证 CDN HTTP 响应。
- 定位结论：旧脚本和代理指令仅靠自然语言约定；新实现加入精确 SKU、可解码图片、Main/yuv420p/tv、隔离 Git、远端 ref 和 CDN 回执门禁。
- 临时处理：不适用。
- 后续动作：新增 SKU 按 `RESULT_JSON` 状态机处理；真实 Git/Ozon 写入仅在任务需要时执行。

## 风险模板（按需复制）
- 风险标题：组合 SKU 被错误地用标题或多单品来源推断
- 触发条件：组合 SKU 不在 xlsx 时，模型凭名称、相近 SKU 或任一组成单品选择图片。
- 影响范围：组合视频、Ozon 媒体属性和组合 SKU 的处理状态。
- 当前判断：组合采购价表可证明一部分单一单品组成关系；多单品组合仍没有足够证据选取代表图片。
- 缓解措施：已只允许组合采购价表中唯一的单品组成回退；回执同时记录目标组合 SKU、来源单品 SKU、数量和映射文件。
- 跟进动作：多单品组合保持 BLOCKED，除非另有组合专属图片或明确授权的素材策略。
